# Apex AI — Build Tools

Setup installers and development tools for the Apex AI build environment.

## Additional resources

For more files and documentation, see the [Google Drive folder](https://drive.google.com/drive/folders/1Qe8jOGzXTlQLW40sy51wbKxbetB6CO-I?usp=sharing).

## Contents

### DABoard Build Tool (x64) 2.1.0

Split archive in `DABoard-BuildTool-Setup-x64-2.1.0/` (8 parts: `part1.rar` through `part8.rar`).

1. Download all parts into the same folder.
2. Extract `part1.rar` with [WinRAR](https://www.winrar.com/) or 7-Zip. The remaining parts are joined automatically.

### MC POS Build Tool 2.1.0

Split archive in `MC POS Build Tool Setup 2.1.0/` (14 parts: `part01.rar` through `part14.rar`).

1. Download all parts into the same folder.
2. Extract `part01.rar` with WinRAR or 7-Zip. The remaining parts are joined automatically.
